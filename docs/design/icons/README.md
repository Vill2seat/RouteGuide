## Использование

Спрайт содержит отдельные `<symbol>` с `currentColor` и `viewBox="0 0 24 24"`. В web-прототипе:

```html
<svg width="24" height="24" aria-hidden="true">
  <use href="/icons/route-guide-icons.svg#walk"></use>
</svg>
```

Цвет не зашит в пиктограммы; назначайте его из дизайн-токенов интерфейса. Для Flutter/React Native импортируйте SVG как ресурс через принятую в проекте библиотеку или экспортируйте из исходника отдельные SVG/векторные drawable. При переносе сохраняйте ID и контрастную альтернативу текстом. Не используйте цвет как единственный индикатор качества маршрута.
